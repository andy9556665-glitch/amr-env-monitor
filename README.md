# 環境抗生素抗藥性資訊匯流站

「環境面化學物質與抗生素風險治理計畫」的國際資訊與文獻追蹤儀表板。每週一自動蒐整國際組織、各國主管機關公告與學術文獻，依計畫 10 類收納標準分類並撰寫摘要，發布在 GitHub Pages。

- 網站：`index.html`（讀取 `data/items.json`）
- 每週流程：見 [AUTOMATION.md](AUTOMATION.md)
- 人工審查：在 Google 試算表「環境抗生素抗藥性資訊彙整表」的「審查狀態」欄改為「已審」。若要同步到網站，把 `data/items.json` 中該筆的 `review` 改為 `"已審"`。

所有內容由 AI 輔助整理，經研究團隊回查原始文件與審查後，才可作為研究或政策研析依據。
